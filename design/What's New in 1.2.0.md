## Promo text

A Kanban board for your GitHub issues, plus instant launch, faster sync and moves, label editing, an activity log and copy to multiple repos.

## What's New in 1.2

KANBAN BOARD
• New Kanban view (View > Kanban View): drag issues between columns to change their status. Columns are configurable in Settings > Kanban (2–6 states).
• Drag to reorder cards within a column; drag several selected cards at once.
• Closing an issue now moves it to your Done column.

MUCH FASTER
• Your issue list now appears instantly when you open the app; it updates in the background.
• Background sync only fetches what changed, so it's lighter and quicker.
• Dragging a card between Kanban columns is about twice as fast.
• ⌘R refreshes quickly. Use View > Reload All Issues (⇧⌘R) to re-download everything.
• Issues deleted on GitHub are removed from the list as soon as you open them.
• New Settings > General > Local Cache > Clear Cache & Reload, if the list ever looks out of date.

NEW FEATURES
• Add or remove labels from an issue's right-click menu, or create a new label on the spot.
• Copy an issue to several repositories at once.
• The issue detail now shows GitHub's activity log (labels, assignments, open/close) alongside comments. You can turn this off in Settings.
• A progress bar shows background changes as they're processed.
• Issues in archived (read-only) repositories are hidden by default. Turn them on in Settings > General > GitHub Access.
• New issues default to the repository you used last.
• A second "Add Comment" link at the top of the issue detail.
• Keyboard and mouse shortcuts: ⌘S saves an issue or comment, ⌘R refreshes, and double-click opens an issue for editing.

FIXES
• Issues in repositories owned by your GitHub organisations now appear.
• An edit you save is no longer briefly overwritten by a background sync.
• The issue detail scrolls properly when your pointer is over the description or a comment, and the description's height is now correct.
• The repository filter is now sorted alphabetically.
