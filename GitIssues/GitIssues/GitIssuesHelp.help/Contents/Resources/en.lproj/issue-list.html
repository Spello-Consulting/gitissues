The Issue List

What Each Row Shows

Each issue in the list displays:

  • Pin icon — hollow when unpinned, filled when pinned. Click to toggle.
  • State icon — green circle for open issues, purple filled checkmark for closed.
  • Title — up to two lines. The full title is visible in the detail panel.
  • Issue number — shown as #123 in the top-right of the row.
  • Repository — displayed as owner/repo.
  • Last updated — shown as a relative time, e.g. "3 hours ago".
  • Labels — colour-coded badges below the repository line. Scroll horizontally if there are many.

Searching

The search bar at the top of the list filters issues in real time as you type. Search is case-insensitive and matches against:

  • Issue title
  • Issue body / description
  • Repository name

Click the ✕ button to clear the search. Your last search query is restored when you relaunch the app.

Sorting

Use the Sort menu in the filter bar to change the order of the list. The available options are:

OptionDescription
Updated (Newest)Most recently updated first (default)
Updated (Oldest)Least recently updated first
Created (Newest)Most recently created first
Created (Oldest)Oldest issues first
Issue # (High to Low)Highest issue numbers first
Issue # (Low to High)Lowest issue numbers first
Note Pinned issues always appear at the top of the list, regardless of the sort order.

Pinning Issues

Pinning keeps important issues at the top of your list so they are always easy to find.

  • Click the pin icon on any issue row to pin it. The icon turns solid.
  • Click again to unpin.
  • Pinned issues are sorted among themselves using the current sort order.
  • Pin state is saved locally and restored between sessions.
Tip You can pin issues from any repository. There is no limit on the number of pinned issues.

Selecting Issues

  • Single click — selects one issue and shows its details in the right panel.
  • ⌘ click — adds or removes an issue from the selection without deselecting others.
  • Shift click — selects a range of issues.
  • Return — when a single issue is selected, opens it for editing.

When more than one issue is selected, the detail panel switches to batch operation mode. See Batch Operations for details.

The Context Menu

Right-click any issue to reveal a context menu. The available actions depend on whether you have one or multiple issues selected:

  • Single issue: Edit, Clone, Assign, Labels…, Copy/Move to Repository, Close/Reopen, Delete.
  • Multiple issues (right-click a selected item): Clone all, Assign all, Close open ones, Delete all.

Editing with the Mouse

Double-click an issue to open it for editing — the same as selecting it and pressing Return.

Refreshing

Issues are kept up to date automatically if background sync is enabled in Settings. You can also click the ↺ toolbar button, or press ⌘R, at any time to fetch the latest data from GitHub. The list remains visible while the refresh happens in the background.
