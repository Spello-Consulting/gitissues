Keyboard Shortcuts

Issue List

ShortcutAction
ReturnOpen the selected issue for editing (single selection only)
Double-clickOpen the clicked issue for editing (list and Kanban board)
⌘RRefresh issues from GitHub (main window only)
⌘ clickAdd or remove an issue from a multi-selection
⇧ clickSelect a range of issues

Issue & Comment Forms

ShortcutAction
⌘SSubmit the form (Create Issue, Save Changes, Add Comment)
EscapeCancel and close the form window

Sheets (Assign, Label Picker, Repository Picker)

ShortcutAction
⌘ReturnConfirm and close the sheet
EscapeCancel and close the sheet

Application

ShortcutAction
⌘,Open Settings
⌘?Open this Help book
⌘WClose the front window
⌘QQuit GitIssues
Tip In the Markdown editor, the editor toolbar provides clickable buttons for all formatting actions. Hover over any button to see its label.
