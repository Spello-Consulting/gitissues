Settings

Open Settings from the GitIssues menu › Settings… or press ⌘,.

Choose the display mode for the app:

OptionDescription

DarkAlways use the dark appearance

Background Sync

GitIssues can automatically refresh your issues in the background so the list stays up to date without you having to click Refresh.

Enable/Disable

Use the toggle (Automatically sync issues with GitHub) to turn background sync on or off. It is enabled by default.

Sync Interval

When background sync is on, use the interval picker to choose how often issues are fetched:

OptionInterval
10sEvery 10 seconds
15sEvery 15 seconds
30sEvery 30 seconds (default)
60sEvery minute
2 minEvery 2 minutes
5 minEvery 5 minutes
Tip A shorter interval keeps your list more current but uses more network traffic and GitHub API quota. The 30-second default is a good balance for most workflows.

Issue Detail

The Show GitHub activity log toggle controls whether the issue detail panel lists GitHub's activity log (label changes, assignments, open/close events, renames and so on) in line with the comments. It is on by default. Turn it off if you only want to see comments.

GitHub Access

Private Repository Access

The Allow private repository access toggle controls whether GitIssues requests permission to see your private repositories.

  • Off (default): Only public repositories and their issues are shown.
  • On: Public and private repositories are shown. Enabling this requires re-authenticating with GitHub to grant the additional permission.

Reducing Permissions

If you previously enabled private access and want to revert to public-only, turn the toggle off. A Reduce permissions (re-authenticate) button appears — click it to go through the sign-in flow again with the narrower scope. Your locally stored issues and preferences are not affected.

Note Revoking app access entirely can be done from your GitHub account at github.com › Settings › Applications › Authorized OAuth Apps.
