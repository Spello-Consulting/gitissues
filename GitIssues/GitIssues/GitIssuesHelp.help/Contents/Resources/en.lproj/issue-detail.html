Viewing an Issue

Click any issue in the list to open it in the detail panel on the right.

Header

At the top of the detail panel you'll find:

  • Title — displayed in large bold text.
  • State badge — shows Open (green circle) or Closed (purple checkmark).
  • Issue number — shown as #123.

Action Buttons

The top-right corner of the detail panel contains several buttons:

ButtonAction
EditOpens the Edit Issue window
Assign (person icon)Opens the Assign sheet to add or change assignees
Pin (pin icon)Pins or unpins the issue. Icon is filled when pinned.
Share (share icon)Copies the issue's GitHub URL to the clipboard. The button briefly animates to confirm.
Delete (trash icon)Permanently deletes the issue after a confirmation prompt

Metadata

Below the header, a metadata row shows:

  • The issue author and when they opened it
  • Created date and last updated date
  • The repository (owner/repo)

Labels

If the issue has labels, they appear as colour-coded badges below the metadata. The colour of each badge matches the label's colour on GitHub.

Assignees

If the issue has assignees, they are listed below the labels section. To change assignees, click the Assign button in the header.

Description

The issue body is rendered as GitHub-flavoured Markdown, including:

  • Bold and italic text
  • Headings
  • Bulleted and numbered lists
  • Code blocks (inline and fenced)
  • Blockquotes
  • Tables
  • Images and links
  • Task lists (checkboxes)

If the issue has no description, No description provided is shown in italics.

An Add Comment link also sits at the top of the panel, next to the issue author's name, so you don't have to scroll past a long description to reach it.

Comments

The comments section appears below the description and shows a count of comments (e.g. Comments (3)). Each comment shows:

  • The author's name
  • How long ago the comment was posted (relative time)
  • The comment body, rendered as Markdown
  • Edit (pencil) and Delete (trash) buttons

Click Add Comment (at the top of the panel or below the comments) to post a new comment. See Comments for details.

Activity Log

GitHub's activity log is shown in line with the comments, oldest first: labels added or removed, assignments, the issue being closed or reopened, title changes, milestones, locking, and pull requests or issues that mention this one. (Changes to the app's own kanban- labels are not shown.) To hide the activity log, turn off Show GitHub activity log in Settings › General.

Deleting an Issue

Click the Delete button (trash icon) in the header. A confirmation dialog appears before the issue is permanently removed. Deletion cannot be undone.

Important Deleting an issue removes it permanently from GitHub. This action cannot be reversed.
