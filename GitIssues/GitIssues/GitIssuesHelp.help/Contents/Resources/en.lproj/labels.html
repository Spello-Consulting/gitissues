Labels

Labels are colour-coded tags that categorise issues. They are defined per repository on GitHub and appear as badges throughout GitIssues.

Viewing Labels

Labels appear as coloured badges in:

  • The issue row in the list (horizontal scroll if there are many)
  • The detail panel header area
  • The issue form when creating or editing

Filtering by Label

Use the Labels button in the filter bar to filter the issue list by one or more labels. See Filtering Issues for details.

Adding Labels to an Issue

Labels can be added when creating a new issue or when editing an existing one:

  1. Open the Create Issue or Edit Issue window.
  2. In the Labels section, click any label badge to select it. A checkmark appears and the background darkens.
  3. Click again to deselect.
  4. Save or create the issue to apply the changes.

Labels from the Context Menu

You can also change an issue's labels without opening the edit form. Right-click a single issue and choose Labels…:

  1. A dialog lists every label in the issue's repository. The issue's current labels are ticked.
  2. Tick or untick labels to add or remove them.
  3. Click the + button to create a new label in the repository — it is selected for the issue automatically.
  4. Click Save to apply the changes.

Creating a New Label

If the label you need doesn't exist in the repository yet, you can create it directly from the issue form — no need to visit GitHub.

  1. Open the Create Issue or Edit Issue window.
  2. Click the + (plus) button next to the Labels heading. A popover appears.
  3. Enter a name for the new label.
  4. Click one of the 16 preset colour swatches to choose the label colour.
  5. Click Create. The label is created on GitHub, added to the label list, and automatically selected for the current issue.
Tip The + button only appears once a repository has been selected and the labels have finished loading.
Note Creating a label requires write access to the repository. If you only have read access, the Create button will result in an error.

Label Colours

When creating a label, choose from 16 preset colours that match GitHub's standard label palette. The colour can be changed later directly on GitHub if needed.
